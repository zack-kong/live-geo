# AgenticGEO

## Evaluated method

Strategy selection using the released critic and strategy archive.

- Paper: [AgenticGEO: A Self-Evolving Agentic System for Generative Engine Optimization](https://arxiv.org/abs/2603.20213)
- Official code: [https://github.com/AIcling/agentic_geo](https://github.com/AIcling/agentic_geo)

## LIVE-GEO adaptation

We used the released strategy-selection components and archive to guide
rewriting, with GPT-4.1 as the text generator. The instructions were adapted to
product descriptions and seven review titles/bodies. We used the released critic
with its existing weights.
