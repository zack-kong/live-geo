# Statistics Addition

## Evaluated method

The quantitative-enrichment baseline from the original GEO study.

- Paper: [GEO: Generative Engine Optimization](https://arxiv.org/abs/2311.09735)
- Official code: [https://github.com/GEO-optim/GEO](https://github.com/GEO-optim/GEO)

## LIVE-GEO adaptation

We used the released statistics-addition instructions with GPT-4.1, adapting
them to product descriptions and seven review titles/bodies. The released prompt
includes hypothetical statistical additions as part of its enrichment strategy.
