# Strategy documentation

Each subdirectory contains a README describing the evaluated strategy, its paper
and official code, and our LIVE-GEO adaptation. Implementations are available in
the linked author repositories; the catalogue contains our evaluated outputs.

Common adaptation: released rewriting instructions were applied to product
descriptions and extended to seven review titles/bodies. Fixed product records and
review identities, order and ratings were retained. The four non-CORE strategies
used GPT-4.1. CORE retained its ranking-feedback workflow.
