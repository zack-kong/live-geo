# C-SEO

## Evaluated method

The released ContentImprovement transformation from C-SEO Bench.

- Paper: [C-SEO Bench: Does Conversational SEO Work?](https://arxiv.org/abs/2506.11097)
- Official code: [https://github.com/parameterlab/c-seo-bench](https://github.com/parameterlab/c-seo-bench)

## LIVE-GEO adaptation

We used the author ContentImprovement entry point and postprocessing, with
GPT-4.1 as the common generator. Product descriptions and seven review titles and
bodies were carried through the adaptation.
